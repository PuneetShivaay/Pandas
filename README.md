A structured collection of hands-on tutorials, code snippets, and Jupyter notebooks covering foundational to advanced data manipulation, cleaning, and analysis workflows using Python's **Pandas** library.

---

## 📚 Core Topics Covered

- 🧱 **Series & DataFrames:** Creation, indexing, slicing, and attribute inspection.
- 🧹 **Data Cleaning:** Handling missing values (`NaN`), filtering duplicates, renaming, and type casting.
- 🔄 **Transformations & Reshaping:** Merging, joining, concatenation, pivot tables, and `melt`.
- 📊 **Aggregation & Grouping:** `groupby()`, custom aggregations, and window/rolling operations.
- ⏱️ **Time Series:** Date parsing, shifting, resampling, and date-range operations.
- 💾 **I/O Operations:** Reading and exporting datasets (CSV, Excel, JSON, Parquet, and SQL).

## 🛠️ Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/PuneetShivaay/Pandas.git
cd Pandas
```

### 2. Set Up a Virtual Environment
```bash
# Create virtual environment
python -m venv venv

# Activate on Windows
venv\Scripts\activate

# Activate on macOS/Linux
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install pandas numpy jupyter matplotlib seaborn
```

### 4. Launch Jupyter Notebook
```bash
jupyter notebook
```
